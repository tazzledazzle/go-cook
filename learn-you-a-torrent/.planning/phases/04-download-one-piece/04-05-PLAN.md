  <action>
    func DownloadPiece(conn *peer.Connection, tor *torrent.Torrent, index int, w *file.Writer) error
    Flow:
    1. Read messages until unchoke (skip bitfield/keepalive)
    2. conn.SendInterested()
    3. Read until unchoke if not yet seen
    4. piece := NewPiece(int(tor.Info.PieceLength))
    5. For begin := 0; begin < pieceLength; begin += BlockSize:
       blockLen := min(BlockSize, pieceLength - begin)
       conn.SendRequest(uint32(index), uint32(begin), uint32(blockLen))
       Read until MsgPiece for this index/begin → WriteBlock
    6. hash, _ := tor.Info.PieceHash(index); if !piece.Validate(hash) { return error }
    7. w.WritePiece(index, piece.Bytes()); w.Close()
    Use context-free blocking reads (match Phase 3 style); single peer sequential.
  </action>
